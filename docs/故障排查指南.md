### 步驟 2: 找到 API 端點 (20 分鐘) ⭐ 關鍵步驟

這是解決問題的關鍵！

**方法 A: 瀏覽器開發者工具 (推薦)**

1. 打開網站
   ```
   https://vbs.sports.taipei/venues/?K=352
   ```

2. 按 `F12` 打開開發者工具

3. 進入 `Network` 標籤

4. **刷新頁面** (Ctrl+R 或 Cmd+R)

5. 在請求列表中查找：
   - 輸入 "api" 進行篩選
   - 或者查找 "XHR/Fetch" 類型的請求
   - 查找返回 JSON 的請求

6. 點擊找到的請求，查看：
   - **Headers 標籤**:
     - 完整 URL (Request URL)
     - 方法 (GET 或 POST)
     - 查詢參數
   - **Response 標籤**:
     - 應該是 JSON 格式
     - 包含時段 (slot) 或預訂 (booking) 數據

7. 記錄找到的 API URL

**示例:**
如果找到的 URL 是：
```
https://vbs.sports.taipei/api/venues/352/slots?date=2026-05-06
```

### 場景 2: 網站需要登入

如果網站明確需要登入才能查看時段信息：

**解決方案:**
```python
# 創建 scraper_with_login.py
import requests

def fetch_venue_slots_with_login(username, password):
    session = requests.Session()
    
    # 登入
    login_url = "https://vbs.sports.taipei/login"
    session.post(login_url, data={
        "username": username,
        "password": password
    })
    
    # 訪問時段頁面
    venue_url = "https://vbs.sports.taipei/venues/?K=352"
    resp = session.get(venue_url)
    
    # 現在可以解析頁面
    # ...
```

📝 如果需要此方案，請提供：
- 登入用戶名
- 登入密碼
- 登入頁面 URL

## 💡 技巧和建議

### 技巧 1: 使用瀏覽器的 "複製為 cURL"

在 Network 標籤中找到請求後：
1. 右鍵點擊請求
2. 選擇 "複製為 cURL"
3. 粘貼到文本編輯器
4. 這會顯示完整的請求細節（包括所有 headers）

### 技巧 2: 檢查 localStorage 和 cookies

1. 打開開發者工具
2. 進入 Application 標籤
3. 查看 Cookies 和 LocalStorage
4. 這可能包含 API 端點 URL 或訪問令牌

### 技巧 3: 查看頁面源代碼

1. 按 Ctrl+U (或右鍵 > 查看頁面源代碼)
2. 搜索 (Ctrl+F): "api", "slot", "booking"
3. 可能會找到隱藏的端點 URL
