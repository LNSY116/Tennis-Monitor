# 🎾 網球場時段數據抓取異常 - 完整診斷報告

## 📊 問題診斷結果

### 現象
網球場時段數據無法正常抓取，系統返回空結果。

### 根本原因
✅ **已確認**: 時段數據 **不在** 初始 HTML 頁面中加載

**技術分析:**
1. ✅ 網站可以正常訪問 (HTTP 200)
2. ✅ 網站包含 VenuesInfoJson 變量（包含場地基本信息）
3. ❌ VenuesInfoJson 中 **不包含** slotDataDay (時段數據)
4. ❌ 頁面中也 **不存在** DataPickup 元素
5. ⚠️ 頁面含有"登入"字樣，表明需要登入才能查看完整數據

---

## 🔍 為什麼找不到時段數據？

### 原因 #1: 數據通過 AJAX / API 動態加載 🔴
**可能性: 極高**

網站很可能在用戶登入後，通過 JavaScript 代碼動態從 API 端點獲取時段數據。

**證據:**
- 初始 HTML 頁面很小 (89 KB)
- 包含大量 JavaScript 代碼
- VenuesInfoJson 只含基本信息，不含時段數據

### 原因 #2: 需要用戶登入 🟠
**可能性: 高**

頁面明確包含"登入"的文本，表明部分功能需要登入。

時段數據可能是登入用戶才能看到的信息。

### 原因 #3: 網站反爬蟲防護 🟡
**可能性: 中**

網站可能有：
- JavaScript 渲染要求
- Token 驗證
- User-Agent 檢查
- IP 限流

---

## 💡 解決方案

### 方案 A: 使用 Selenium (推薦) ⭐⭐⭐
**適用於: 需要 JavaScript 渲染 + 登入**

優點:
- ✅ 支持完整的 JavaScript 渲染
- ✅ 可以處理動態內容加載
- ✅ 可以實現自動登入

缺點:
- ❌ 速度較慢（需要啟動瀏覽器）
- ❌ 資源消耗較大

**安裝:**
```bash
pip install selenium webdriver-manager
```

**示例代碼:**
```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.chrome.service import Service

def fetch_venue_slots_selenium(venue_id="352"):
    options = webdriver.ChromeOptions()
    options.add_argument("--headless")  # 無頭模式
    options.add_argument("--no-sandbox")
    options.add_argument("--disable-dev-shm-usage")
    
    driver = webdriver.Chrome(
        service=Service(ChromeDriverManager().install()),
        options=options
    )
    
    try:
        url = f"https://vbs.sports.taipei/venues/?K={venue_id}"
        driver.get(url)
        
        # 等待 AJAX 請求完成
        WebDriverWait(driver, 10).until(
            EC.presence_of_all_elements_located((By.CSS_SELECTOR, "td[id^='DataPickup.']"))
        )
        
        # 現在可以解析頁面
        slots = []
        cells = driver.find_elements(By.CSS_SELECTOR, "td[id^='DataPickup.']")
        # ... 處理 cells
        
        return {"slots": slots, "alerts": []}
    
    finally:
        driver.quit()
```

優點:

- ✅ 可靠性高

- ❌ 需要先找到 API 端點和參數

**步驟:**
1. 打開網站: https://vbs.sports.taipei/venues/?K=352
2. 打開瀏覽器開發者工具 (F12)
3. 進入 Network 標籤
4. 刷新頁面或等待數據加載
5. 查找以下特徵的請求:
   - 方法: GET 或 POST
   - URL 中包含: /api, /booking, /slot
   - 響應是 JSON 格式
6. 記錄該請求的 URL 和參數

**示例 API 調用:**
```python
import requests
import json

def fetch_via_api(venue_id="352"):
    """
    一旦找到 API 端點，可以直接調用它
    示例 URL（需要根據實際情況調整）
    """
    api_url = "https://vbs.sports.taipei/api/venues/slots"
    params = {
        "venue_id": venue_id,
        "date_from": "2026-05-06",
        "date_to": "2026-05-20"
    }
    
    resp = requests.get(api_url, params=params)
    data = resp.json()
    return data
```

### 方案 D: 使用 Playwright (現代替代方案) ⭐⭐⭐
**適用於: JavaScript 渲染 + 現代框架**

比 Selenium 更快、更可靠

**安裝:**
```bash
pip install playwright
python -m playwright install chromium
```

**示例:**
```python
from playwright.sync_api import sync_playwright

def fetch_with_playwright(venue_id="352"):
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()
        page.goto(f"https://vbs.sports.taipei/venues/?K={venue_id}")
        
        # 等待動態內容加載
        page.wait_for_selector("td[id^='DataPickup.']", timeout=10000)
        
        # 解析頁面
        # ...
        
        browser.close()
```
