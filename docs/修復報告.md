
## 📞 故障排除

### 問題: "404 This model is no longer available"
- **原因**: 模型已停用或無訪問權限
- **解決**: 運行 `python check_models.py` 查看可用模型

### 問題: "Missing required environment variables"
- **原因**: .env 文件缺失或配置不完整
- **解決**: 複製 .env.example 為 .env 並填入真實密鑰

### 問題: "Telegram Bot Token invalid"
- **原因**: 令牌已失效或格式錯誤
- **解決**: 在 Telegram BotFather 中重新建立 Bot

### 問題: "AI 服務暫時無法回應"
- **原因**: Google API 配額已用完或服務繁忙
- **解決**: 等待數分鐘後重試，或檢查 Google Cloud 配額
