# 🎾 网球场时段数据抓取异常 - 完整诊断报告

## 📊 问题诊断结果

### 现象
网球场时段数据无法正常抓取，系统返回空结果。

### 根本原因
✅ **已确认**: 时段数据 **不在** 初始 HTML 页面中加载

**技术分析:**
1. ✅ 网站可以正常访问 (HTTP 200)
2. ✅ 网站包含 VenuesInfoJson 变量（包含场地基本信息）
3. ❌ VenuesInfoJson 中 **不包含** slotDataDay (时段数据)
4. ❌ 页面中也 **不存在** DataPickup 元素
5. ⚠️ 页面含有"登入"字样，表明需要登入才能查看完整数据

---

## 🔍 为什么找不到时段数据？

### 原因 #1: 数据通过 AJAX / API 动态加载 🔴
**可能性: 极高**

网站很可能在用户登入后，通过 JavaScript 代码动态从 API 端点获取时段数据。

**证据:**
- 初始 HTML 页面很小 (89 KB)
- 包含大量 JavaScript 代码
- VenuesInfoJson 只含基本信息，不含时段数据

### 原因 #2: 需要用户登入 🟠
**可能性: 高**

页面明确包含"登入"的文本，表明部分功能需要登入。

时段数据可能是登入用户才能看到的信息。

### 原因 #3: 网站反爬虫防护 🟡
**可能性: 中**

网站可能有：
- JavaScript 渲染要求
- Token 验证
- User-Agent 检查
- IP 限流

---

## 💡 解决方案

### 方案 A: 使用 Selenium (推荐) ⭐⭐⭐
**适用于: 需要 JavaScript 渲染 + 登入**

优点:
- ✅ 支持完整的 JavaScript 渲染
- ✅ 可以处理动态内容加载
- ✅ 可以实现自动登入

缺点:
- ❌ 速度较慢（需要启动浏览器）
- ❌ 资源消耗较大

**安装:**
```bash
pip install selenium webdriver-manager
```

**示例代码:**
```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.chrome.service import Service

def fetch_venue_slots_selenium(venue_id="352"):
    options = webdriver.ChromeOptions()
    options.add_argument("--headless")  # 无头模式
    options.add_argument("--no-sandbox")
    options.add_argument("--disable-dev-shm-usage")
    
    driver = webdriver.Chrome(
        service=Service(ChromeDriverManager().install()),
        options=options
    )
    
    try:
        url = f"https://vbs.sports.taipei/venues/?K={venue_id}"
        driver.get(url)
        
        # 等待 AJAX 请求完成
        WebDriverWait(driver, 10).until(
            EC.presence_of_all_elements_located((By.CSS_SELECTOR, "td[id^='DataPickup.']"))
        )
        
        # 现在可以解析页面
        slots = []
        cells = driver.find_elements(By.CSS_SELECTOR, "td[id^='DataPickup.']")
        # ... 处理 cells
        
        return {"slots": slots, "alerts": []}
    
    finally:
        driver.quit()
```

### 方案 B: 找到隐藏的 API 端点 ⭐⭐⭐
**适用于: API 直接访问（无需浏览器）**

优点:
- ✅ 速度快
- ✅ 资源消耗少
- ✅ 可靠性高

缺点:
- ❌ 需要先找到 API 端点和参数

**步骤:**
1. 打开网站: https://vbs.sports.taipei/venues/?K=352
2. 打开浏览器开发者工具 (F12)
3. 进入 Network 标签
4. 刷新页面或等待数据加载
5. 查找以下特征的请求:
   - 方法: GET 或 POST
   - URL 中包含: /api, /booking, /slot
   - 响应是 JSON 格式
6. 记录该请求的 URL 和参数

**示例 API 调用:**
```python
import requests
import json

def fetch_via_api(venue_id="352"):
    """
    一旦找到 API 端点，可以直接调用它
    示例 URL（需要根据实际情况调整）
    """
    api_url = "https://vbs.sports.taipei/api/venues/slots"
    params = {
        "venue_id": venue_id,
        "date_from": "2026-05-06",
        "date_to": "2026-05-20"
    }
    
    resp = requests.get(api_url, params=params)
    data = resp.json()
    return data
```

### 方案 D: 使用 Playwright (现代替代方案) ⭐⭐⭐
**适用于: JavaScript 渲染 + 现代框架**

比 Selenium 更快、更可靠

**安装:**
```bash
pip install playwright
python -m playwright install chromium
```

**示例:**
```python
from playwright.sync_api import sync_playwright

def fetch_with_playwright(venue_id="352"):
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()
        page.goto(f"https://vbs.sports.taipei/venues/?K={venue_id}")
        
        # 等待动态内容加载
        page.wait_for_selector("td[id^='DataPickup.']", timeout=10000)
        
        # 解析页面
        # ...
        
        browser.close()
```
